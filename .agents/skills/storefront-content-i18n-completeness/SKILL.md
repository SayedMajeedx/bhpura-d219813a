# اكتمال المحتوى متعدد اللغات (Storefront Content i18n Completeness)

## متى تستخدم هذا الـ skill
- أي صفحة إدارة "الصفحات والسياسات" أو CMS للمتجر.
- أي حقل نص يُدخل بأكثر من لغة (تبويبات EN/AR أو ما شابه).
- أي صفحة قانونية (الشروط والأحكام، سياسة الخصوصية، سياسة الإرجاع).
- قبل عملية إطلاق (launch) أي متجر جديد على المنصة.

## خطوات الفحص الإلزامية

### 1. فحص الحقول الفارغة عبر كل اللغات المدعومة (Cross-Language Field Completeness)
لكل حقل نص يدعم أكثر من لغة (عناوين مجموعات الفوتر، أسماء الأقسام،
عناوين صفحات)، تحقق من أن **كل لغة مفعّلة بإعدادات المتجر لها قيمة
مدخلة فعلياً**، وليس فقط اللغة الافتراضية أو الإنجليزية. إذا وُجد
حقل معبّأ بلغة وفارغ بلغة أخرى:
- حدد فوراً ماذا يحدث بالواجهة الأمامية عند عرض اللغة الفارغة: هل
  يظهر نص فارغ (فجوة بصرية)، أو يسقط تلقائياً (fallback) للغة أخرى،
  أو يظهر مفتاح الترجمة الخام (translation key) للعميل؟
- بلّغ عن كل حقل فارغ بلغة معينة كمشكلة "عالية" على الأقل إذا كانت
  تلك اللغة هي اللغة الأساسية المعلنة للمتجر (مثال: متجر عربي بالأساس
  وحقل العنوان العربي فارغ رغم امتلاء الإنجليزي).

### 2. فحص محتوى الصفحات القانونية (Legal Content Validation)
لأي صفحة ذات أثر قانوني أو تعاقدي (الشروط والأحكام، سياسة الخصوصية،
سياسة الإرجاع والاستبدال، الشحن والتوصيل)، لا تكتفِ بالتحقق من وجود
الصفحة بالقائمة — **افتح محتواها فعلياً** وتحقق من:
- أنها ليست فارغة أو قالب افتراضي عام غير مخصص لنشاط المتجر الفعلي
  (مثال: سياسة إرجاع بدون مدة زمنية محددة أو شروط فعلية).
- أن حالة النشر (منشورة/مسودة) ظاهرة بوضوح بقائمة الصفحات نفسها، لا
  تتطلب فتح كل صفحة على حدة لمعرفة إذا كانت منشورة.
- أن تاريخ آخر تحديث ظاهر، خصوصاً للصفحات القانونية التي قد تحتاج
  مراجعة دورية مع تغيّر سياسات الدولة أو النشاط.

### 3. فحص ترتيب وربط روابط التذييل (Footer Link Integrity)
تأكد من أن كل رابط بمجموعات الفوتر يشير فعلياً لصفحة منشورة وموجودة
(لا رابط معطّل 404)، وأن ترتيب السحب والإفلات المحفوظ بلوحة الإدارة
يطابق فعلياً ترتيب العرض بالواجهة الأمامية.

### 4. فحص اللغة الافتراضية عند فشل الترجمة
حدد بوضوح سلوك النظام عند عرض المتجر بلغة ليس لها محتوى مُدخل: هل
يسقط بصمت للغة افتراضية (سلوك مقبول لو موثق)، أو يعرض فراغاً/خطأ؟
هذا السلوك يجب أن يكون **موحّداً عبر كل الحقول**، لا يختلف حقل عن حقل.

## Output المطلوب من الـ agent
1. جدول بكل حقل متعدد اللغات تم فحصه، وحالة الاكتمال لكل لغة مدعومة.
2. قائمة بأي صفحة قانونية فارغة أو غير منشورة فعلياً رغم ظهورها بالقائمة.
3. تأكيد سلوك fallback الموحّد عند غياب الترجمة بأي حقل.
4. قائمة بأي رابط فوتر معطّل أو يشير لصفحة غير منشورة.
