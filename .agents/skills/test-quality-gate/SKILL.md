# Test Quality Gate

- اختبر النتيجة والسلوك المرئي أو الأثر على البيانات، لا تفاصيل التنفيذ فقط.
- اجعل mocks تعكس واجهة العميل الحقيقية، خصوصاً سلاسل query builders.
- للمسارات الحساسة، غطِّ الرفض قبل الوصول للكتابة واثبت أن write لم يُستدعَ.
- لا تعتمد على اختبار وحدة وحده لإثبات RLS أو عزل tenant؛ أضف اختباراً تكاملياً عند توفر بيئة آمنة.
- احتفظ بحالات الحافة: مدخلات فارغة، صفر سابق في النسب، تكرار الطلب، وبيانات من tenant آخر عندما تنطبق.
