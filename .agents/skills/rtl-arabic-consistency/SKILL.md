# تناسق اللغة العربية وRTL (RTL Arabic Consistency)

## متى تستخدم هذا الـ skill
- أي صفحة أو كومبوننت جديد بواجهة عربية.
- أي حقل يعرض قيمة خام من الداتابيس مباشرة (slug، enum، category key).
- أي مكان فيه أرقام، تواريخ، عملة، أو أكواد منتجات وسط نص عربي.
- أي رسالة خطأ أو تنبيه أو حالة (status) جديدة تُضاف للنظام.

## خطوات الفحص الإلزامية

### 1. كشف "التسريب التقني" (Technical Leakage)
ابحث عن أي قيمة تقنية داخلية (database slug, enum value, internal key)
تُعرض للمستخدم النهائي بدون ترجمة، مثل: `dresses-under-abaya`, `abayas`,
`pending_payment`. هذه القيم يجب أن يكون لها **طبقة ترجمة (i18n mapping
layer)** منفصلة عن الـ key الداخلي:
```
category_key: "dresses-under-abaya" → عرض: "فساتين تحت العباية"
```
أي مكان يعرض الـ key مباشرة بدون مرور بطبقة ترجمة = مشكلة يجب تصليحها.

### 2. فحص خلط الحالات المتشابهة بصرياً
لما يكون فيه حالتين (statuses) لهما نفس اللون أو نفس الشكل البصري تقريباً
لكن معناهما مختلف (مثال: "تم الاستلام" العامة مقابل "تم الاستلام من الخياط"
المخصصة)، هذا خطر التباس تشغيلي حقيقي. تأكد من:
- لون مختلف واضح، أو
- أيقونة مختلفة، أو
- بادج (badge) بنمط مختلف تماماً (outline مقابل filled مثلاً)
لأي حالتين قد يشتبه بهما موظف يراجع بسرعة.

### 3. فحص محاذاة الأرقام والأكواد داخل RTL
النص العربي RTL لكن الأرقام والأكواد اللاتينية (مثل "S17"، "#1096"،
أرقام الهواتف) تبقى LTR داخل الجملة. تأكد أن:
- لا يحدث انقلاب بصري (mirroring) لأكواد المنتجات أو أرقام الفواتير.
- الفواصل العشرية والآلاف تتبع تنسيق العملة الصحيح (د.ب. مثلاً بالبحرين
  تُكتب بعد الرقم وليس قبله، خلافاً للدولار).
- استخدم `dir="auto"` أو `unicode-bidi: isolate` للحقول المختلطة بدل
  الاعتماد على اتجاه الصفحة العام فقط.

### 4. فحص أسماء العملاء والبيانات المُدخلة من المستخدم
أسماء العملاء أحياناً تُكتب بالإنجليزية (Zainab) وأحياناً بالعربية (رقية)
داخل نفس الجدول. هذا طبيعي (بيانات مستخدم حرة) لكن تأكد إن الفرز
(sorting) والبحث (search) يشتغلون صح على الحالتين معاً، وإن محاذاة
الجدول ما تنكسر بصرياً بين الصفوف.

### 5. فحص النصوص التوضيحية (Microcopy)
راجع كل جملة تعريفية/وصفية جديدة للتأكد إنها:
- منطقية وذات معنى واضح بالسياق (لا كلمات ملتصقة خطأ من ترجمة آلية).
- متسقة بالمصطلحات عبر كل الشاشات (مثلاً: "الطلب" لازم تستخدم نفس الكلمة
  بكل مكان، مو "الطلب" بمكان و"الأوردر" بمكان ثاني).

## Output المطلوب من الـ agent
1. قائمة بكل نص/قيمة تقنية تسربت للواجهة بدون ترجمة، مع مكانها بالكود.
2. قائمة بأي حالتين (statuses) متشابهتين بصرياً بمعنى مختلف.
3. اقتراح نص عربي بديل لأي microcopy ركيكة، مع تبرير مختصر.
4. تأكيد إن كل حقل رقم/عملة/تاريخ يتبع تنسيق البحرين (BHD, +973) أو
   تنسيق الدولة المستهدفة الصحيح لكل tenant.
