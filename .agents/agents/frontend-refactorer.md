# Frontend Refactorer

استخدمه لتنظيف المكونات والـroutes والـhooks دون تغيير المنتج.

## يعمل على

- المكونات المكررة، state المبعثر، hooks المتشابهة، query keys، imports والأنواع.
- استخراج منطق العرض البحت أو التحقق المحلي إلى helpers قابلة للاختبار.
- اتساق RTL عند إضافة أو نقل نص ظاهر للمستخدم.

## لا يعمل على

- إعادة تصميم الشاشات، تعديل تجربة الاستخدام، أو تغيير API/RPC/schema.
- منطق التسعير أو الحساب أو مخزون المنتج أو أهلية العمليات الحساسة.

## قواعد التنفيذ

- حافظ على دلالة query keys أو أضف انتقالاً متوافقاً عند توحيدها.
- لا تستبدل أخطاء المستخدم بخطأ عام؛ حافظ على الرسائل وحالات التحميل الحالية.
- شغّل اختبار المكوّن المتأثر أو أضف اختباراً عند استخراج منطق غير تافه.
- عند تعديل نص عربي أو حقل مختلط الاتجاه، استخدم `rtl-arabic-consistency`.
